# v0.7.2 — A simpler welcome and more practical learning

## Highlights

- **A clearer first introduction:** Brain explains memory in everyday language,
  asks about your work and checks what it understood before saving. It follows
  your language, uses a friendly tone and shows simple ways to remember, recall
  or forget information. The nonexistent `/brain-help` command is gone; Google
  Drive, OneDrive and Git are presented as optional storage choices.
- **Learning that leads to action:** `brain-autolearn` tracks the status and
  last-seen date of repeated problems, handles at most one ready, allowed item
  per pass and archives inactive candidates. A registry and per-tool ledger
  record use and friction with your own tools; safety defects are captured
  on first sight rather than waiting for repetition.

## Worth knowing before you upgrade

These changes update the Brain skills and starter memory-folder README.
Preserve local skill customizations before refreshing installed skills.

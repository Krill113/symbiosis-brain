# Symbiosis Brain — Vault

Это твоя общая память с Claude. Markdown-файлы, которые Claude может читать,
писать и связывать через `[[wiki-links]]`.

## Структура

Память разложена по проектам: у каждого проекта своя папка, её имя — это его
`scope`. Внутри — заметки этого проекта, и там же его карточка
`<scope>/<scope>.md`: с неё Claude начинает каждую сессию и в неё же записывает,
на чём ты остановился.

```
<scope>/<scope>.md   карточка проекта — статус, решения, на чём остановились
<scope>/…            заметки этого проекта
<scope>/files/       материалы: не заметки, в поиск не попадают
global/              то, что верно везде: привычки, приёмы, предпочтения
```

**Пока заметок мало, они лежат прямо в папке проекта — это нормально.**
Раскладывать по подпапкам вручную не нужно: когда однотипных накопится заметно
много, Claude разложит их сам. Папка при этом задаёт тип — то, что лежит в
`decisions/`, имеет `type: decision`. В `global/` подпапки заведены сразу, там
записи появляются с первого дня.

| Папка | Что хранится |
|---|---|
| `decisions/` | зафиксированные решения с обоснованием |
| `patterns/` | повторяющиеся приёмы |
| `mistakes/` | ошибки прошлого с уроками |
| `wiki/` | долгоживущая справочная информация |
| `feedback/` | правила работы — от тебя для Claude |
| `research/` | исследования и обзоры |
| `reference/` | канонические справочники и таблицы |
| `projects/` | планы и рабочие срезы проекта |
| `archive/` | то, что отслужило, но выбрасывать жалко |

В корне лежат файлы, которые никуда не переезжают: этот `README.md`,
`CRITICAL_FACTS.md` (кто ты и чем занимаешься — читается в начале каждой сессии),
`MEMORY.md` (запасной путь, когда MCP недоступен) и `reference/scope-taxonomy.md`
— список известных проектов (в корне, не внутри проекта).

## Scope (область видимости)

Каждая заметка имеет `scope:` во frontmatter — `global` или конкретный проект.
Сессии видят свой scope + `global`. Список валидных scope-ов:
`reference/scope-taxonomy.md`. Новый scope регистрирует skill `brain-project-init`.

## Wiki-ссылки

`[[<scope>/decisions/foo]]` или `[[global/patterns/some-rule]]` создают граф
связей. Откроется
красиво в Obsidian, работает и без него.

## Команды

- «Запомни…» (`/brain-save`) — сохранить важное на будущее.
- «Что ты помнишь про…» (`/brain-recall`) — найти нужное в заметках.
- «Забудь…» — уберу из заметок то, что скажешь.

Можно запомнить и стиль общения: «Запомни: отвечай кратко, без жаргона».
Названия в скобках — готовые инструкции для помощника; учить их не нужно.

## Хранение и синхронизация

Заметки — обычные текстовые файлы в папке на твоём компьютере. Храни их там,
где тебе удобно. Если нужна копия на другом устройстве, можно настроить
синхронизацию через Google Диск, OneDrive или Git (систему хранения истории
изменений). Git не обязателен; Symbiosis Brain сам не подключает эти сервисы.
Выбирая облачную папку, проверь, у кого будет доступ к твоим заметкам.

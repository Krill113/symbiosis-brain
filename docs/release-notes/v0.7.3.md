# v0.7.3 — Signed writes and a lighter hook

## Highlights

- ✍️ **Every write says who made it.** The four writing tools take an optional
  `model` and `role`, and a note records `written_by: <client>/<version> <model> <date>`.
  `brain_append` now keeps what was there: each block gets its own footer, so a
  handoff shows which actor wrote which part instead of one anonymous body.
  A missing or malformed model becomes `unknown` — provenance never blocks a write.
- 🤝 **The clients fill it in themselves.** The Claude pre-action hook reads the
  calling actor's own transcript, so a subagent is signed as the subagent, not as
  the session that spawned it. Codex and OpenCode pass their session's model.
- ⚡ **One Python process per prompt.** The recall hook used to start several; it
  now starts one, and the installer refreshes its own Python path during setup.
- 🔕 **Task notifications are not prompts.** Recall, route hints and auto-save skip
  `<task-notification>` turns. Rules context, compaction, relay and the turn
  counter still run, and a real message that merely mentions the marker is
  still treated as a prompt.

## Worth knowing before you upgrade

- The statusline model bridge is gone: the server no longer reads `brain-model-*`
  files. The context and rate-limit exports are unchanged, and a custom statusline
  that sources `sb-export.sh` keeps working.
- Signatures are additive. Existing notes keep their old `written_by` until their
  next write, and `brain_append` leaves earlier blocks untouched.
- **Close every Claude Code window before upgrading.** `uv tool upgrade symbiosis-brain`,
  then `symbiosis-brain setup claude-code --repair` — a package upgrade alone does
  not refresh `~/.claude/hooks` or `~/.claude/skills`. Preserve local skill
  customizations first if you have any.
